# 흰여울 한 바퀴

부산 영도 흰여울문화마을을 위한 모바일 우선 관광 안내 웹앱입니다.

- 목적: 명소·카페·맛집·포토스팟을 한 화면에서 안내하고 주민 생활 구역을 배려하는 산책 경로를 제공합니다.
- 실행: `index.html` 파일을 웹 브라우저로 여세요.
- 지도: 이 버전은 프로토타입이며, 지도는 실제 축척이 아닌 개략도입니다.
- 데모 이동: Web Geolocation API 없이 동작을 시연합니다. 이후 실제 지도 API 연동, GPS 실시간 안내, 접근성 정보, 다른 마을 확장을 고려할 수 있습니다.
- GitHub Pages: 저장소 루트에 파일을 올린 뒤 Settings → Pages에서 배포 브랜치와 루트 폴더를 선택하면 됩니다.
